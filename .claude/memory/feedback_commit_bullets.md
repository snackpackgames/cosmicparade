metadata:
  type: feedback
---

Use bullet points instead of paragraphs for commit message body details.

**Why:** Scannable, structured commit bodies are preferred over prose.

**How to apply:** When writing multi-line commit messages, format the body as a bulleted list of changes rather than a paragraph summary. See [[feedback-logical-commits]] for how to slice the commits themselves.
